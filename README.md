Базовые правила

- Игра представляет собой компьютерную викторину по мотивам телешоу «Кто хочет стать миллионником?».
- В главном меню игрок выбирает один из трёх уровней сложности: лёгкий, средний или сложный.
- Для каждого уровня сложности программа случайно отбирает 15 вопросов из банка в 30 вопросов.
- На экране отображаются текст вопроса, варианты ответов, текущий выигрыш и доступные подсказки.
- Игрок продолжает игру, пока отвечает правильно. При неправильном ответе игра заканчивается.
- Подсказка «50/50» — убирает два неверных варианта ответа.
- Подсказка «Пропуск вопроса» — позволяет перейти к следующему вопросу без выбора ответа, сохраняя текущий выигрыш.
- Каждая подсказка может быть использована только один раз за игровую сессию.
- При выходе в главное меню через специальную кнопку прогресс не сохраняется (игрок получает предупреждение).
- При выходе из игры во время сессии через кнопку закрытия прогресс сохраняется в JSON-файл (пройденные вопросы, выигрыш, использованные подсказки, сгенерированный банк вопросов).
- При успешном прохождении всех 15 вопросов игрок получает максимальный выигрыш и становится победителем.

Управление

- Кнопка слева сверху (три полоски) — выход в меню.
- Кнопка справа сверху (громкоговоритель) — включение/выключение звука.
- Кнопка справа сверху крайняя (иконка выключения) — выход из игры.
- Кнопка слева снизу крайняя (наклонная линия) — активация подсказки (убирает два неправильных ответа).
- Кнопка слева снизу (стрелки вправо) — активация подсказки (пропуск вопроса).
